# IronPulse — Gym Management UI Prototype

Clickable UI prototype for a multi-branch gym management platform: staff console (dashboard, front desk check-in, members, member 360, new sale, classes & PT, leads) and member app (home & rotating QR pass, class booking, progress).

Open `index.html` to start. Static site, no build step; `support.js` is a tiny runtime that renders the `*.dc.html` screens.

All names, numbers and prices are sample data. "IronPulse" is a placeholder name.
